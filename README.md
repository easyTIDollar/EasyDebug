# EasyDebug 🚀

一款极致轻量、优雅的 Android 无线调试快捷开关工具。专为 Root 玩家打造，告别繁琐的系统设置菜单，一键开启生产力！

## ✨ 核心特性

* **⚡️ 秒级开关**：利用 Root 权限直接修改系统底层参数，拒绝页面跳转，一键秒开/秒关 WiFi 与无线调试。
* **🧲 下拉磁贴 (Tile)**：支持将快捷开关添加到系统下拉通知栏，无需打开 App 即可随时随地掌控状态。
* **📡 状态透视**：开启后自动捕获并显示当前设备的局域网 IP 和随机 ADB 端口，方便电脑端精准连接。
* **🎨 纯血 MD3 设计**：采用原生 Jetpack Compose 构建，完美支持沉浸式边缘到边缘 (Edge-to-Edge) 体验。
* **🌈 Material You 动态主题**：适配 Android 12+ 动态取色，UI 颜色随系统壁纸自动呼吸变化；内置多款精美预设调色盘。

## 📱 环境要求

* **系统版本**：Android 11 及以上 (依赖系统原生无线调试特性)
* **权限要求**：必须具备 **Root 权限** (支持 Magisk / KernelSU / APatch 等)

## 📥 下载与安装

本项目已配置 GitHub Actions 自动化构建。
请前往仓库的 **[Releases]** 页面，下载最新版本的 `.apk` 安装包。

## 🛠️ 开发者指南

本项目极度精简，采用纯 Kotlin 开发。如果想要自行编译或修改：

1. 克隆项目到本地。
2. 使用 Android Studio (建议最新版) 打开项目。
3. 自动同步 Gradle 依赖后即可点击运行。

**关于自动发布 (CI/CD)：**
当推送带有 `v*` 前缀的标签 (如 `git tag v1.0.0` & `git push origin v1.0.0`) 时，GitHub Actions 会自动编译 APK 并发布到 Releases 页面。
